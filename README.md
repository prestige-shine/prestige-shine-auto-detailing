# Prestige Shine Auto Detailing

Official website for Prestige Shine Auto Detailing, an owner-operated automotive detailing business based in Miramichi, New Brunswick, Canada.

The website provides information about detailing services, recent vehicle work, the Prestige Shine team, and customer lead/quote forms.

## Tech Stack

* React
* TypeScript
* TanStack Start
* Vite
* Tailwind CSS
* Supabase
* EmailJS

## Local Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

## Environment Variables

Environment variables are stored locally in `.env` and are not committed to the repository.

Required environment variables should be configured through the deployment platform for production.

## Project Structure

* `src/routes` — Website pages and routes
* `src/components` — Reusable website components
* `src/lib` — Shared utilities, data, and integrations
* `src/integrations` — Supabase and other service integrations
* `supabase/migrations` — Database migrations

## Deployment

The production website is intended to be deployed through Netlify.

The GitHub repository is the source of truth for the website code.
